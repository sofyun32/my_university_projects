Для сборки и запуска игры "Skul: The Hero Slayer" требуется предвари-тельная установка необходимых зависимостей. Основными зависимостями являются среда Visual Studio и библиотека SFML (Simple and Fast Multimedia Library) версии 2.5.x или выше, которая обеспечивает работу с графикой, зву-ком и вводом данных. Проект написан на языке C++ с использованием стан-дарта C++17 или выше. Для сборки проекта необходим компилятор с под-держкой стандарта C++17, такой как MSVC 2019+.
Процесс сборки начинается с загрузки исходного кода игры. Затем необходимо убедиться, что библиотека SFML установлена в системе. В Windows рекомендуется использовать менеджер пакетов vcpkg или загрузить бинарные файлы с официального сайта SFML.
После установки зависимостей выполняется сборка проекта. Для этого необходимо открыть файл решения (Game.sln) в Visual Studio, выбрать кон-фигурацию сборки (Debug или Release) и целевую платформу (x86 или x64), а затем выполнить сборку решения. В результате будет создан исполняемый файл игры.
Запуск игры осуществляется через полученный исполняемый файл.
